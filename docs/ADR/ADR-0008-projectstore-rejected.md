# ADR-0008. SmartAndPoint/ProjectStore - отклонён, две идеи забираем

Статус: **принято** (аудит кода 2026-07-30, Opus-субагент; решение в grill-сессии). Дата: 2026-07-30.

## Решение

Плагин https://github.com/SmartAndPoint/ProjectStore не внедряем.
Несмотря на имя, это не хранилище спек, а "память проекта" поверх Obsidian-vault:
ADR, эпики, stories, kanban-доска, продолжение сессий.

**Не путать три вещи:** ProjectStore (чужой плагин) ≠ `openspec store` (механизм OpenSpec)
≠ cybernet-specs (наш центральный репозиторий спек, ADR-0001).

## Почему отклонён

1. **Нет multi-repo** - провал фильтрующего критерия №1.
   Один vault на проект, ссылки на код резолвятся от корня одного репозитория.
   У нас 5 репозиториев.
2. **Не может быть гейтом** - провал критерия №2.
   Его проверка (doctor, 17 чеков) всегда завершается успешно, даже когда нашла проблемы.
3. **Дублирует то, что уже выбрано**: доска и stories - это YouTrack;
   его ревьюеры - наши ECC-ревьюеры; его "археолог" - наш spec-miner;
   его карта кода - Graphify.
4. **Не жилец**: один мейнтейнер, 48 коммитов, 5 звёзд, без тестов и CI,
   последний коммит 2026-07-03, версия до 1.0.
5. Конфликтует с нашими решениями: пишет свой блок в CLAUDE.md
   (у нас это симлинк на AGENTS.md с бюджетом 500 строк, ADR-0002)
   и тащит 18 команд + 5 агентов + 3 hooks - против чистки обвеса (ADR-0004).

Единственный его настоящий плюс - хранение решений с отклонёнными альтернативами.
Мы это уже делаем руками в `./` (эта директория), плагин для этого не нужен.

## Две идеи, которые портируем в sdd-kit (реализовано 2026-07-30)

1. **PreCompact-hook**: перед сжатием контекста сохранять "пакет выживания" -
   активный `openspec/changes/<id>` и последние правки, чтобы агент после сжатия
   продолжил работу, а не выяснял всё заново. Такого hook у нас нет.
2. **Формат находок doctor**: каждая находка - группа, уровень, код, файл
   и точная команда исправления. Плюс приём "перегенерируй производный файл
   настоящим генератором и сравни с закоммиченным" - годится для проверки
   свежести спек в `spec-lint.py`.
